Better language translation for more training content in Kinyarwanda - education-specific machine translation for the Moodle Learning Management System

Country: Rwanda | SDG 4 | Data: Text | License: Permissive | Maturity: Dataset > Model > Pilot

Enabling language translation capabilities on the Moodle LMS platform, through a collaboration with Atingi; the use case explores 3 modes of translation. The first mode is navigation based, simply translating static messages such as buttons and notifications, secondly it explores full content translation, lastly, in-line translation. The project uses the NLLB-200 model for translation, other models could be experimented to explore feasibility of additional features such as QA or summarization, leveraging the plugin built by the team.

Data characteristics

Parallel datasets can be used to finetune LLMs to specific languages or domains; the example is for English-Kinyarwanda, to improve NLLB translation performance

Model characteristics

Open source model NLLB-200, some variations quantized to minimize compute resource usage

How to use

Integrate preferred machine translation model with Moodle plugin: https://github.com/Digital-Umuganda/moodle-translate_courses . Need to update for compatibility with newer Moodle updates, this was implemented during Moodle version 3.0
